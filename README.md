# MCC Melody for PIC16 - Capacitive Touch (CapSense)

Control LED using capacitive touch with PIC16F18446, configured via MCC Melody Touch Library.

## 📹 Video Tutorial
https://youtu.be/xnxWcn_VB8E

## 🛠️ Tools & Hardware
- MPLAB X IDE v6.25
- MCC Melody
- PIC16F18446
- PICkit

## 📋 What it does
- Uses MTOUCH library to read capacitive touch input (Button 0)
- LED turns ON when touch is detected, OFF when released
- No mechanical switch required — touch sensing handled by hardware and MCC Touch Library
